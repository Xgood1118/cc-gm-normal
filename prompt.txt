## 需要完成

1. **方向**
   - 高度上升方向的法线倾向要符合切线空间惯例，凹坑与凸起在图上的颜色方向要相反。
   - 采用哪种惯例（Y 向上还是 Y 向下）要在 README 写清。

2. **长度**
   - 所有法线都必须是单位向量，长度误差不超过 1e-3。
   - `strength` 变化时，法线倾斜角随之变化，但长度保持 1。

3. **边界**
   - 画面四周不能出现成片的错误平坦区，边界处理方式写进 README。
   - 高度图突变边缘处不能出现颜色溢出。

4. **色彩**
   - 高度值要先当作线性值再求梯度，README 说明如何处理。
   - 输出 PNG 的颜色空间要明确，并保证读回后数值不被二次转换。

5. **测试**
   - 覆盖：平面区域法线指向正上方、凸起与凹陷方向相反、法线单位长度、边界不出平坦带。
   - `python -m pytest tests -q` 全部通过。

最小与最大值、圆台边缘与斜脊处的倾斜角贴进 README。
