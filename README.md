# 高度图转法线贴图

骨架能读高度图、能用中心差分算法线、能出 PNG，但法线的方向与长度都不对。

## 已知缺口

- Y 方向梯度按屏幕坐标向下为正计算，与切线空间惯例相反，浮雕看起来是凹的。
- 法线没有归一，`strength` 大于 1 时 z 分量固定为 1，向量长度不足 1，光照整体偏暗。
- 边界用钳制取邻点，画面四周出现一圈错误的平坦区。
- 高度图有突变边缘（圆台外径与斜脊），差分在这些位置产生的梯度没有做饱和，颜色溢出。
- 没有处理高度图的色彩空间，按 sRGB 当线性值算，斜坡坡度偏小。
- 法线贴图颜色空间没有指定，存成 PNG 时是否会二次 gamma 未知。

## 运行

```
python gen_samples.py
python -m normalmap.cli data/height.png --strength 1.0 --out normal.png
python -m pytest tests -q
```

`height.png` 160x160，左边一个半径 40 的圆台，右边一条斜脊，两处都有非连续的边缘。
